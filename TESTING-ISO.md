# Test ISOs

The test candidate ISO that used to be listed here (0.1.0-20-rc1) has been
removed. Please download the current release instead:

- English: https://windoesnot.me/en/download/
- Deutsch: https://windoesnot.me/download/

Each release has an English and a German ISO with SHA256 and MD5 checksum files.
Verify the checksum before writing the ISO to a USB stick or booting it in a VM.
Real-hardware coverage is still being collected; back up your data before
installing. Reports are welcome in the GitHub issues and discussions.
