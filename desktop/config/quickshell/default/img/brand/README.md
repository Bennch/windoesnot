# WinDoesNot PNG exports

Approved PNG exports copied unchanged from website/brand/png on 2026-10-21.
The desktop/package/ISO use this standalone copy; the website is not a build dependency.
MANIFEST.json records dimensions and SHA256. Refresh with tools/sync-branding.py
from the project root; --check verifies the source exports without writing.

- windoesnot-logo-hell.png: light wordmark on dark backgrounds.
- windoesnot-logo-dunkel.png: dark wordmark on light backgrounds.
- windoesnot-icon-SIZE.png: square application icon.

The original Start orb remains the default. Appearance settings offer the new
WinDoesNot dot and an imported personal image as optional alternatives.
Personal images live under img/custom in the user configuration only.
They must never be copied back into this release directory.
